## Reproduction and limits

From the workspace in PowerShell, run:

```powershell
python scripts/inspect_pe.py CK2game.exe --output artifacts
Get-FileHash -LiteralPath CK2game.exe -Algorithm SHA256
```

The script uses Python's standard library and reads the copied target as bytes. It creates the three inventory artifacts and prints a bounded summary. It does not execute, load as a library, patch, or modify the target. Its outputs are local static evidence rather than REA evidence IDs. It is an inventory parser for this valid PE, not a hardened parser for hostile malformed inputs.

No fleet or combat function, object layout, field offset, or pseudocode is established by this inventory. The next step is to follow Ghidra references to the string seeds and inspect callers, data access, and control flow in the persistent analysis database.
